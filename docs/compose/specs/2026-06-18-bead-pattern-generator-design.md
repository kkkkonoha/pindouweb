# 拼豆图纸生成器 - 设计文档

## [S1] 项目概述

**拼豆图纸生成器** — 一个纯前端Web应用，帮助拼豆爱好者快速将图片/文字/手绘转换为可编辑的拼豆图纸。

### 目标用户
- 拼豆爱好者/手工玩家
- 有拼豆经验，需要快速生成图纸

### 核心特点
- 纯前端实现，无需后端服务器
- 多种输入方式（图片/文字/手绘）
- 支持全品牌拼豆颜色系统
- 可编辑项目 + 自定义模板导出

---

## [S2] 功能需求

### 2.1 输入模块

#### 图片输入
- 支持 JPG/PNG/GIF/BMP 格式
- 上传后自动像素化处理
- 可调整网格大小（29x29, 58x58, 116x116 等）
- 自动颜色量化，匹配最接近的拼豆颜色

#### 文字像素化
- 输入任意文字
- 选择像素字体/风格
- 选择文字大小
- 实时预览像素文字效果

#### 手绘输入
- 提供空白画布
- 支持铅笔工具（单点绘制）
- 支持油漆桶工具（区域填充）
- 支持橡皮擦工具
- 支持取色器工具

### 2.2 画布引擎

#### 网格系统
- 可调网格大小
- 网格线显示/隐藏切换
- 参考线辅助

#### 绘图工具
- 铅笔：单点绘制
- 油漆桶：区域填充
- 取色器：拾取颜色
- 橡皮擦：清除像素
- 矩形选择：批量操作

#### 视图控制
- 缩放（滚轮/按钮）
- 平移（拖拽/空格+拖拽）
- 适应窗口

#### 历史记录
- 撤销（Ctrl+Z）
- 重做（Ctrl+Y）

### 2.3 颜色管理

#### 品牌支持
- Perler Beads
- Artkal Beads
- 国产拼豆（拼酷、思乐等）
- Hasbro/other

#### 颜色匹配算法
- 使用 CIEDE2000 色差公式
- 自动匹配最接近的拼豆颜色
- 显示匹配结果和色差

#### 调色板
- 显示当前图纸使用的颜色
- 显示每种颜色的用量
- 支持手动替换颜色

### 2.4 导出系统

#### PNG导出
- 像素网格图
- 颜色标注
- 可选是否显示网格线

#### PDF导出
- 完整图纸
- 颜色对照表
- 用豆数量统计
- 制作说明

#### SVG导出
- 矢量格式，可无限缩放
- 适合高质量打印

#### 自定义模板
- 预设多种模板布局
- 用户可调整模板元素
- 保存自定义模板

## [S4] 技术选型

### 4.1 前端技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | React + TypeScript | 组件化开发，类型安全 |
| 构建 | Vite | 快速开发，HMR |
| 状态管理 | Zustand | 轻量级，适合中等规模 |
| Canvas | 原生 Canvas API | 高性能像素操作 |
| 样式 | Tailwind CSS | 快速UI开发 |
| 导出 | html2canvas + jsPDF | 图片和PDF导出 |

### 4.2 核心算法

#### 像素化算法
```
1. 读取原图 ImageData
2. 根据目标网格大小计算缩放比例
3. 使用双线性插值进行缩放
4. 输出像素化后的 ImageData
```

#### 颜色匹配算法
```
1. 将 RGB 转换为 Lab 色彩空间
2. 使用 CIEDE2000 公式计算色差
3. 在目标品牌颜色库中查找最小色差
4. 返回最接近的拼豆颜色
```

#### 文字像素化算法
```
1. 创建离屏 Canvas
2. 使用选择的字体渲染文字
3. 读取像素数据
4. 根据阈值二值化
5. 输出像素文字
```

## [S6] 数据结构

### 6.1 项目数据

```typescript
interface Project {
  id: string;
  name: string;
  width: number;           // 网格宽度
  height: number;          // 网格高度
  pixels: PixelData[][];   // 像素数据
  palette: PaletteColor[]; // 使用的颜色
  brand: string;           // 选择的品牌
  createdAt: Date;
  updatedAt: Date;
}

interface PixelData {
  color: string;           // 颜色代码
  beadCode?: string;       // 拼豆色号
}

interface PaletteColor {
  color: string;           // 颜色代码
  beadCode: string;        // 拼豆色号
  beadName: string;        // 拼豆名称
  count: number;           // 使用数量
}
```

### 6.2 品牌颜色数据

```typescript
interface BrandColor {
  code: string;            // 色号
  name: string;            // 名称
  hex: string;             // HEX颜色值
  rgb: [number, number, number]; // RGB值
  lab: [number, number, number]; // Lab值（预计算）
}
```
